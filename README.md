## 🚀 使用方法

1. 打开本仓库的 Releases 页面。
2. 选择需要的资料版本。
3. 在 Assets 区域下载对应 ZIP 文件。
4. 下载完成后，使用 7-Zip 或其他兼容解压工具解压。
5. 阅读压缩包内的使用说明，再按照说明配置和使用。

建议下载前确认磁盘空间充足，并确保网络连接稳定。

## 🔐 文件完整性与安全

为了保证资料在发布和下载过程中保持完整，正式发行版本应提供 SHA-256 校验信息。

下载后可以使用 Windows PowerShell 执行：

```powershell
Get-FileHash "你的文件路径" -Algorithm SHA256
```

将计算结果与对应版本公布的 SHA-256 值进行比较。

如果两者不一致，请不要运行文件，应重新下载并检查文件来源。

对于 EXE、脚本及其他可执行文件，请在运行前确认其来源和安全性。
